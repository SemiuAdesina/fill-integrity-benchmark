# Reference repair plan

Validate the bounded fabric, derive every aligned decoder compatible with the
observations, and globally select the minimum non-overlapping canonical set.
Interpret both endpoints of each DMA range through the resulting map. Finally,
for every used host/device pair choose the minimum-cost route, resolving ties by
the documented hop-sequence ordering. No observed answer is stored in a lookup
table; translations and DMA predictions are computed from recovered decoders.
