## How the four required properties are met

**Global optimum.** The objective is biconvex: with the parental haplotypes fixed each progeny is an independent Viterbi pass over the 100 joint inheritance states; with the paths fixed the markers decouple. `search` alternates the two halves inside 6 seeded restarts with perturbation, and `exact` then runs branch and bound over the column sequence in marker order, each node carrying one forward vector per progeny. Two admissible bounds prune (paths consistent + optimistic per-progeny columns; shared columns + free states), `reach` lookahead orders the options, and `rows_still_sorted` removes the entire 24×24 relabelling class from the tree. On this cross the B&B closes the gap in ~0.2 s. As a stress check I temporarily ran 60 seeds (10× effort) — same total to all digits.

**Internal consistency.** `total_log_likelihood` is what the frozen scorer computes; I verified it independently in Python from the spec (not using the frozen scorer), and confirmed the reported paths are exactly optimal for the reported haplotypes and that no single-marker column change improves them.

**Canonical.** Rows sorted, then the parent's path signature minimised, then the permutation image — per `spec/result-format-v1.md`. `solve` takes the minimum of `distinct_key` over every assignment the B&B found within 1e-8 of the optimum crossed with every row-sorting relabelling, and `canonicalize` relabels the winner. Validated against `examples/small.result.json` (the duplicate-row case) and checked to be a fixed point under all 576 relabellings.

**Deterministic.** Fixed seeds, fixed node budget (`NODE_WORK / offspring`), no clock anywhere. Two consecutive runs are byte-identical (`md5 a56a9ac7…` twice).
