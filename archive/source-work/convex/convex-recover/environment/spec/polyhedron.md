# Exact halfspace model

Offsets, vertices and supports are reduced rationals with positive denominators.
Triple intersections outside any selected closed halfspace are discarded.
Coincident intersections become one vertex. Full dimension requires four
affinely independent vertices. A selected plane is nonredundant only if at least
three noncollinear vertices lie on it. Boundedness rejects every nonzero recession
direction. Canonical face incidence is the sorted set of exact on-plane vertices.
