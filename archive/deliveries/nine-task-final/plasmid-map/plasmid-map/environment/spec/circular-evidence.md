# Frozen circular evidence semantics

Known-block domains bound site placement but do not score it. Digest fragments
are circular clockwise distances, including the last-to-first wrap. Observations
are unordered multisets. Sorted equal-cardinality matching minimizes total
absolute error; errors at tolerance are accepted. Junctions are undirected
circular adjacency plus orientation parity, which is preserved when a complete
map is reversed and all orientations flip. Canonical maps normalize all site
positions relative to each possible origin in both directions.
